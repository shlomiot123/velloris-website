עבודה בוולוריס

וולוריס היא חברת ייעוץ שמלווה ארגונים בהטמעת AI ואוטומציה בליבת העבודה שלהם. כמפתח/ת אוטומציה אצלנו תיהנו משילוב נוח בין עבודה מהבית לבין ימים בשטח אצל הלקוחות, לצד צוות יועצים מנוסה וחזק שתמיד שמח לעזור. הסביבה אצלנו נעימה, תומכת וגמישה, בדיוק כמו שצריך כדי לעשות את העבודה הכי טובה שלכם.

משרות פתוחות

היקף 1 עד 2 ימים בשבוע

על התפקיד

אנחנו מחפשים מפתח/ת אוטומציה חזק/ה ומנוסה, שהתפקיד שלו/ה ברובו hands on. הסטאק המרכזי: n8n בהתקנה עצמית על Docker עם Postgres, אינטגרציות API למערכות ארגוניות, ושכבת LLM עם פלט מובנה ואישור אנושי. העבודה מתחילה בשטח: לדבר עם מנהלים ועם הצוותים עצמם, להבין קושי עסקי ואופרטיבי, לתרגם אותו לאפיון, ובעיקר לבנות את האוטומציות בעצמך.

מה תעשה/י בפועל

עיצוב זרימת מידע מקצה לקצה, ממקורות מפוזרים לשכבת דאטה אחת מסודרת

ההחלטה איפה עובר הגבול בין חוק דטרמיניסטי לשיקול דעת של מודל

רמת הפרודקשן עצמה: סביבות נפרדות, בדיקות, ניטור, יומן ביקורת, התאוששות מכשלים

השיח עם השטח: מנהלים וצוותים, הבנת קושי, אפיון, ובניית אוטומציה עובדת

דרישות התפקיד

לפחות 3 שנות ניסיון בפיתוח אוטומציות שרצות בפרודקשן בארגונים אמיתיים

שליטה עמוקה ב n8n או Make, כולל יציאה לקוד (JavaScript או Python)

עבודה מעשית מול APIs של מערכות ארגוניות: הרשאות, מגבלות קצב, כשלים, idempotency

שילוב הנדסי של LLMs: פלט מובנה, בקרת עלויות, מדידת איכות, ונפילה לחוק דטרמיניסטי

שליטה ב Git ובסביבת שרת Linux/Docker: פריסה, עדכון ותחזוקה של שירותים בהתקנה עצמית

עברית ברמת שפת אם, בכתב ובעל פה, לשיחה ישירה עם לקוחות ועם הצוותים שלהם

שליטה ב SQL לשליפה ועיצוב נתונים ב Postgres או מסדי נתונים דומים

ניסיון בעבודה ישירה מול לקוחות חיצוניים או בעלי עניין, כיועץ או כפרילנסר

יתרון

תהליכי AI בעברית, היכרות עם מערכות ישראליות (Priority, חשבשבת ודומותיהן), סביבות self hosted, RAG בפרודקשן.

הפנייה מיועדת לכל המגדרים.
